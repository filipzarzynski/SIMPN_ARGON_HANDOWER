## Context & Problem Statement

Although `crates/simon-core/src/receipt.rs` implements **Proof Level 1 (`WiazaniaM1`)** (`Receipt::z_wiazaniem_m1`, `odcisk_promptu`, `lancuch_tokenow`, `odcisk_parametrow`, `odcisk_tokenizera`), **the live node (`crates/simon-cli/src/node.rs:744`) hardcodes `wiazania: None`!**
As a result, every live receipt generated by `simon --role node` is **Proof Level 0** (`r.poziom() == 0`), and Level 1 only exists in synthetic offline fixtures (`examples/gen_m1.rs`).

## Step-by-Step Implementation Instructions

### Task B1: Extend `PromptResponse` with Optional M1 Token Vectors (`crates/simon-harness/src/request_response.rs`)

   Using `#[serde(default, skip_serializing_if = "Option::is_none")]` preserves 100% backward compatibility with older Level 0 nodes/clients!

### Task B2: Fetch Token IDs via `/tokenize` in `node.rs` and Populate `WiazaniaM1`
1. Write a helper `async fn tokenizuj_tekst(model_url: &str, tekst: &str) -> Option<Vec<u32>>` in `crates/simon-cli/src/node.rs`:
   * Sends `POST {baza}/tokenize` with `{"prompt": tekst, "content": tekst}` (2-second timeout).
   * Extracts `v.get("tokens").and_then(|t| t.as_array())`, mapping elements via `as_u64().map(|x| x as u32)`.
   * Returns `Some(vec)` if non-empty, else `None`.
2. Compute a deterministic `tokenizer_hash` via `simon_core::receipt::odcisk_tokenizera(b.model.as_bytes())` (or from a `--tokenizer-file` if provided).
3. In `policz` (`node.rs:297-402`):
   * Attempt to obtain `prompt_token_ids = tokenizuj_tekst(&b.url, &req.prompt).await` and `output_token_ids = tokenizuj_tekst(&b.url, &output).await`.
   * If both succeed (`Some(p_ids)` and `Some(o_ids)`):
     * Build the receipt with `Receipt::z_wiazaniem_m1(format!("{}/{}", b.runtime, b.model), &tok_hash, &req.nonce, &p_ids, &o_ids, &simon_core::receipt::SamplingCommitment::greedy().odcisk()?, 42)` before `.sign(&b.klucz)`!
     * Populate `tokenizer_hash`, `prompt_token_ids`, and `output_token_ids` on `PromptResponse`.
   * If `/tokenize` does not return token arrays (e.g. an endpoint that only returns `"count"`), gracefully fall back to Level 0 (`wiazania: None`).

### Task B3: Verify `zweryfikuj_m1` Automatically in `agent.rs` When Level 1 Data Is Present
