## 2. Master Catalog of Bugs & Security Vulnerabilities Found

### Severity P0 — Hackathon-Visible / Demo-Impacting Bugs
1. **BUG-01 (`crates/simon-cli/src/node.rs:721-724, 740-741`):** `zbuduj_podpisany_receipt` sets both `started_at_us` and `finished_at_us` to the same `teraz` timestamp taken *after* inference finishes. Every live receipt (including all 15 in `ui/src/lib/industry-run.json`) has `0 µs` signed execution duration.
2. **BUG-02 (`crates/simon-cli/src/node.rs:608-639, 731`):** `zbuduj_podpisany_receipt` hardcodes `precision: Precision::Fp16` (even when serving `Q4_0` on RTX 3090 or `BF16` on AMD MI300X), and `wykryj_runtime` doesn't check `llama-server`'s `/props` endpoint, resulting in `"runtime": "nieznany/1"` on all RTX 3090 receipts in `industry-run.json`.
3. **BUG-03 (`crates/simon-core/src/receipt.rs:299-330` & `crates/simon-verify-wasm/src/lib.rs:131-174`):** `Receipt::zweryfikuj_m1` and WASM `weryfikuj_m1` never call `self.verify_self()`, so an unsigned or tampered receipt passes Level 1 (M1) verification.
4. **BUG-04 (`crates/simon-cli/src/agent.rs:738`, `crates/simon-cli/src/main.rs:380`, `crates/simon-verify-wasm/src/lib.rs:84`):** Client agent, CLI offline verifier, and WASM verifier all call `r.verify_self()` instead of checking `r.signer` against an expected node public key (`verify_for_node`).
5. **BUG-05 (`ui/src/lib/components/VerifierPanel.svelte:86-97`):** Browser `/demo` page still marks a receipt `'rejected'` if `ocenaM3` fails (`if (m1Ok && m3Ok) return 'valid'`), contradicting the core thesis that M3 is non-gating telemetry (`SoftFail`).
6. **BUG-06 (`docs/zgloszenie/LABLAB-SUBMISSION.md:34`):** States `median 1.5 s` for the 18-event RTX 3090 + AMD MI300X batch, whereas the actual two-node dataset (`docs/industry/run-3090-mi300x-2026-10-15.jsonl` and `ui/src/lib/industry-run.json`) has `median 1.7 s` (`1,749 ms`).

### Severity P1 — Core Security & Protocol Bugs
7. **BUG-07 (`crates/simon-core/src/web.rs:44-52, 88-96`):** SSRF filter bypass in `prywatny_ip()` and `dozwolony_dns()`: fails to block IPv4-mapped IPv6 addresses (`::ffff:127.0.0.1`, `::ffff:169.254.169.254`), IPv6 Unique Local (`fc00::/7`), IPv6 Link-Local (`fe80::/10`), and bracketed IPv6 literals (`"[::1]"`). Also `host_dozwolony` (`L59`) prepends `.` to entries that doc comment `L26` says already start with `.`.
8. **BUG-08 (`crates/simon-core/src/m3.rs:105-115`):** IEEE-754 `f64::NAN` bypass in `m3::ocena`: `(t1 - *lp).max(0.0)` evaluates to `0.0` when `t1` or `*lp` is `NaN`, passing `margin <= p.max_margin` (`0.0 <= 0.25`). Also `m3::ocena` does not verify that `kr.topk` is sorted descending by logprob.
9. **BUG-09 (`crates/simon-core/src/cap.rs:97-120, 214, 272-316`):** `cap::waliduj` returns `Ok(())` when `parametry` is not a JSON Object (e.g., String/Array/Null) if an action has no required parameters; `cap::sprawdz` ignores `Zezwolenie::budzet`.
10. **BUG-10 (`crates/simon-core/src/tozsamosc.rs:220-229`):** TOCTOU private key exposure window in `zaloz()`: creates `.client.key.<pid>.tmp` with default `umask` (`0o644`), writes plaintext hex `secret_key`, flushes, and only calls `chmod 0o600` afterward.
11. **BUG-11 (`crates/simon-cli/src/node.rs:646-704`):** `odczytaj_realny_ctx` sends `POST /tokenize {"prompt": prompt}` expecting `{"count": N}` (vLLM format), which fails on `llama-server` (expects `{"content": prompt}` returning `{"tokens": [...]}`).
12. **BUG-12 (`crates/simon-core/src/obserwacja.rs:82-86`):** `ClientObservationV1::sign()` does not set `self.client_pubkey = klucz.public()` before hashing `self.digest()`.
13. **BUG-13 (`crates/simon-core/src/protokol.rs:91-93`):** Non-monotonic timestamp in `Kubelek::zezwol` overwrites `self.ostatni_us` and double-credits elapsed time on the subsequent call.
14. **BUG-14 (`crates/simon-harness/src/client_protocol.rs:190-192`):** Unchecked addition `self.wazne_do + TOLERANCJA_ZEGARA_SECS` overflows if `wazne_do == u64::MAX`.
15. **BUG-15 (`crates/simon-harness/src/acp_server.rs:239, 300, 403-414`):** `AcpServer` leaves `order.autoryzacja = None`, accepts unsigned `OrderAccepted::winner`, and hashes raw `SHA256(output)` instead of `odcisk_wyjscia(job_id, output)`.
16. **BUG-16 (`crates/simon-node/src/lib.rs:153-165` & `crates/simon-cli/src/node.rs:120-127`):** `kandydaci_dla_modelu` reads `declared` instead of `attested`; `node.rs` self-populates `attested: Some(...)` and publishes `RegisterMsg` before the gossipsub mesh forms.
